ML Fundamentals

What is Machine Learning?

Machine Learning (ML) is a subset of AI that enables systems to learn patterns from data and make predictions without being explicitly programmed.

Supervised Learning

Trains models using labeled data (e.g., classification, regression).

Unsupervised Learning

Finds patterns in unlabeled data (e.g., clustering).

Reinforcement Learning

Learns by interacting with an environment and receiving rewards.
