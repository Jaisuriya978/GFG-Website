Android Navigation

Moving Between Screens in Android Apps

What is Navigation in Android?

Navigation in Android allows users to move between different screens (Activities or Fragments) within an application.

1. Activity Navigation (Using Intent)

Intents are used to start another Activity. 

val intent = Intent(this, SecondActivity::class.java)
startActivity(intent)

2. Fragment Navigation

Fragments can be replaced dynamically inside an Activity. 

supportFragmentManager.beginTransaction()
    .replace(R.id.fragment_container, ExampleFragment())
    .commit()

3. Navigation Component (Jetpack)

Android Jetpack Navigation Component simplifies navigation between fragments and handles back stack management automatically.

  • Uses Navigation Graph (XML)
  • Supports Safe Args
  • Handles Back Button automatically

Common Navigation Patterns

  • Bottom Navigation
  • Navigation Drawer
  • Tabs (TabLayout + ViewPager)
  • Stack-based Navigation

Best Practices

  • Use Navigation Component for Fragment-based apps
  • Maintain proper back stack
  • Avoid launching too many Activities
  • Follow Material Design guidelines
