Static Members in OOPS

Static Variables, Methods & Blocks

What are Static Members?

Static members belong to the class rather than to individual objects. They are shared among all instances of a class and are accessed using the class name.

Static Data Members

Static variables are common to all objects. Only one copy is created regardless of the number of objects. 


class Student {
    static String college = "ABC College";
    int id;
}

Static Methods

Static methods can access only static data directly. They do not require object creation. 


class MathUtil {
    static int add(int a, int b) {
        return a + b;
    }
}

Static Block

A static block is executed once when the class is loaded. It is mainly used for initialization. 


class Demo {
    static {
        System.out.println("Static block executed");
    }
}

Key Points

  • Static members are shared
  • Accessed using class name
  • Memory efficient
  • Static methods cannot use non-static data

Advantages of Static Members

  • Efficient memory usage
  • Global access within application
  • Useful for utility classes
