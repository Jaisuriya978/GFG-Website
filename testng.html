TestNG

Testing Framework for Selenium

What is TestNG?

TestNG is a testing framework inspired by JUnit and NUnit. It is designed to simplify a wide range of testing needs such as unit testing, integration testing, and functional testing.

Why Use TestNG?

  • Easy test configuration
  • Supports parallel execution
  • Generates detailed reports
  • Annotation-based testing
  • Seamless Selenium integration

TestNG Annotations

  • @BeforeSuite
  • @BeforeTest
  • @BeforeClass
  • @BeforeMethod
  • @Test
  • @AfterMethod
  • @AfterClass
  • @AfterTest
  • @AfterSuite

TestNG Features

  • Grouping test cases
  • Parameterization
  • Dependency testing
  • Data-driven testing
  • Parallel execution

TestNG XML File

testng.xml is used to control test execution. It allows configuring test suites, test groups, parameters, and parallel execution.

Advantages of TestNG

  • Better reporting than JUnit
  • Flexible annotations
  • Supports parallel testing
  • Easy integration with CI tools

TestNG vs JUnit

  • TestNG supports grouping and dependencies
  • JUnit has limited annotations
  • TestNG supports parallel execution
