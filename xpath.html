XPath

Advanced Element Location Technique in Selenium

What is XPath?

XPath (XML Path Language) is used to navigate through elements and attributes in an HTML or XML document. It is widely used in Selenium when other locators fail.

Types of XPath

  • Absolute XPath
  • Relative XPath

Absolute XPath

Starts from the root node and traverses the entire DOM. It is not recommended because it breaks easily when UI changes.

/html/body/div/div/form/input

Relative XPath

Starts with // and is flexible and reliable. It is the most preferred XPath in automation testing.

//input[@id='username']

XPath Using Attributes

//input[@name='email']
//button[@type='submit']

XPath Using Functions

  • contains()
  • starts-with()
  • text()
//input[contains(@id,'user')]
//button[starts-with(@id,'btn')]
//a[text()='Login']

XPath Axes

  • parent
  • child
  • ancestor
  • descendant
  • following
  • preceding
  • following-sibling
  • preceding-sibling
//input[@id='email']/parent::div
//label[text()='Email']/following-sibling::input

Best Practices

  • Avoid absolute XPath
  • Use relative XPath
  • Keep XPath short and readable
  • Prefer unique attributes
