Selenium Commands

Essential WebDriver Methods & Actions

What are Selenium Commands?

Selenium commands are predefined WebDriver methods used to interact with web elements and browsers during automation testing.

Browser Commands

driver.get("https://example.com");
driver.navigate().to("https://example.com");
driver.navigate().back();
driver.navigate().forward();
driver.navigate().refresh();
driver.getTitle();
driver.getCurrentUrl();
driver.close();
driver.quit();

WebElement Commands

element.click();
element.sendKeys("text");
element.clear();
element.getText();
element.isDisplayed();
element.isEnabled();
element.isSelected();

Find Element Commands

driver.findElement(By.id("id"));
driver.findElements(By.className("class"));

Wait Commands

  • Implicit Wait
  • Explicit Wait
  • Fluent Wait
driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(10));

Window & Frame Commands

driver.switchTo().window(windowID);
driver.switchTo().frame("frameName");
driver.switchTo().defaultContent();

Alert Commands

Alert alert = driver.switchTo().alert();
alert.accept();
alert.dismiss();
alert.getText();
alert.sendKeys("text");

Mouse & Keyboard Actions

Actions act = new Actions(driver);
act.moveToElement(element).perform();
act.doubleClick(element).perform();
act.contextClick(element).perform();
act.dragAndDrop(src, dest).perform();

Best Practices

  • Use explicit waits instead of Thread.sleep()
  • Follow Page Object Model
  • Handle exceptions properly
