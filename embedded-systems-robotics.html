Hardware & software brain of a robot

What is an Embedded System?

An embedded system is a combination of hardware and software designed to perform a specific function within a larger system.

In robotics, embedded systems control sensors, actuators, motors, and communication.

Core Components

  • Microcontroller / Microprocessor
  • Sensors
  • Actuators
  • Memory (RAM, ROM, Flash)
  • Power supply

Microcontroller vs Microprocessor

Microcontroller Microprocessor
CPU + Memory + I/O Only CPU
Used in robots Used in computers
Low power High power
