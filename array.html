Array

A collection of elements stored in contiguous memory locations.

DSA Basics

What is an Array?

An Array is a linear data structure that stores elements of the same data type in contiguous memory locations.

Example:

int arr[] = {1, 2, 3, 4, 5};

One Dimensional Array

Stores elements in a single row.

arr[i]

Two Dimensional Array

Stores elements in rows and columns.

arr[i][j]

Basic Operations

  • Traversal
  • Insertion
  • Deletion
  • Searching
  • Sorting

Advantages

  • Fast access using index
  • Easy to implement
  • Efficient memory usage

Disadvantages

  • Fixed size
  • Insertion & deletion are costly

Applications of Array

  • Storing and processing data
  • Searching and sorting algorithms
  • Matrix operations
  • Building other data structures
