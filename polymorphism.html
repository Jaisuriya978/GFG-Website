Polymorphism

One interface, multiple implementations.

OOP Pillar

What is Polymorphism?

Polymorphism means "many forms". It allows methods to perform different tasks based on the object calling them.

Types of Polymorphism

  • Compile-time Polymorphism (Method Overloading)
  • Runtime Polymorphism (Method Overriding)

Method Overloading (Compile-time)

class MathOperation {
    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }
}

Method Overriding (Runtime)

class Animal {
    void sound() {
        System.out.println("Animal makes sound");
    }
}

class Dog extends Animal {
    void sound() {
        System.out.println("Dog barks");
    }
}

public class Main {
    public static void main(String[] args) {
        Animal a = new Dog();
        a.sound();
    }
}

Advantages

  • Flexibility
  • Scalability
  • Code reusability

Real-world Example

Payment system: Credit Card, UPI, Net Banking
Same interface, different implementations.

Key Points

  • Method overloading does not require inheritance
  • Method overriding requires inheritance
  • Runtime polymorphism uses dynamic binding
