Web Fundamentals

What is HTML5?

HTML5 is the fifth and latest version of HyperText Markup Language. It introduces new semantic elements, multimedia support, and powerful APIs.

<!DOCTYPE html>

New Features in HTML5

  • Semantic tags like <header>, <footer>, <article>
  • Audio and Video support
  • Canvas and SVG
  • Local Storage & Session Storage
  • Geolocation API

Semantic Elements

  • <header>
  • <nav>
  • <section>
  • <article>
  • <footer>

Multimedia Tags

  • <audio>
  • <video>
  • <source>

Advantages of HTML5

  • Clean and semantic code
  • Better SEO
  • Mobile-friendly
  • Native multimedia support

Where HTML5 is Used

  • Web applications
  • Mobile apps (Hybrid)
  • Progressive Web Apps (PWA)
