Probability

Understanding Uncertainty and Randomness

What is Probability?

Probability is a branch of mathematics that measures the likelihood of an event occurring. Its value always lies between 0 and 1.

Basic Probability Formula

Probability of an event E is: 


P(E) = Number of favorable outcomes / Total number of outcomes

Types of Probability

  • Theoretical Probability
  • Experimental Probability
  • Subjective Probability

Basic Terminology

  • Sample Space – Set of all possible outcomes
  • Event – A subset of sample space
  • Independent Events
  • Dependent Events

Probability Rules

  • 0 ≤ P(E) ≤ 1
  • P(Sample Space) = 1
  • P(Not E) = 1 − P(E)

Simple Example

Probability of getting a head when tossing a fair coin: 


Favorable outcomes = 1 (Head)
Total outcomes = 2 (Head, Tail)

P(Head) = 1 / 2

Applications of Probability

  • Machine Learning
  • Risk analysis
  • Weather forecasting
  • Finance and stock markets
  • Game theory
