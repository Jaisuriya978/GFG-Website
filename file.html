File Handling in OOPS

Reading, writing, and managing files efficiently

What is File Handling?

File Handling allows programs to store data permanently in files and retrieve it when needed. It enables reading from and writing to external files.

Why File Handling is Important?

  • Permanent data storage
  • Data sharing between programs
  • Efficient data management
  • Supports large data processing

Types of Files

  • Text Files (.txt, .csv)
  • Binary Files (.dat, .bin)

File Streams

  • Input Stream – Read data from file
  • Output Stream – Write data to file
  • Byte Stream
  • Character Stream

Example: Writing to a File (Java)


import java.io.FileWriter;

class WriteFile {
    public static void main(String[] args) throws Exception {
        FileWriter fw = new FileWriter("data.txt");
        fw.write("Hello File Handling");
        fw.close();
    }
}

Example: Reading from a File (Java)


import java.io.FileReader;

class ReadFile {
    public static void main(String[] args) throws Exception {
        FileReader fr = new FileReader("data.txt");
        int ch;
        while((ch = fr.read()) != -1) {
            System.out.print((char)ch);
        }
        fr.close();
    }
}

Exception Handling in File Operations

File handling operations may throw exceptions like IOException. Hence, try-catch or throws keyword is used.

Advantages of File Handling

  • Data persistence
  • Easy data retrieval
  • Efficient storage
  • Supports large applications
