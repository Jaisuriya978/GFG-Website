Scalability in System Design

Designing systems that grow with users and traffic

What is Scalability?

Scalability is the ability of a system to handle increased load (users, traffic, data) without degrading performance.

Types of Scalability

  • Vertical Scaling: Adding more power (CPU, RAM) to a server
  • Horizontal Scaling: Adding more servers to the system

Vertical Scaling

  • Simple to implement
  • Limited by hardware capacity
  • Downtime required for upgrades

Horizontal Scaling

  • Highly scalable and fault tolerant
  • Uses load balancers
  • Preferred in modern cloud systems

Scalability Techniques

  • Load Balancing
  • Caching
  • Database Sharding
  • Asynchronous Processing
  • Microservices Architecture

Real-World Examples

  • Netflix scaling video streaming
  • Amazon handling flash sales
  • WhatsApp scaling messaging
