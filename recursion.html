Recursion

Understand recursive functions, base cases, and real-world applications

What is Recursion?

Recursion is a programming technique where a function calls itself directly or indirectly to solve a problem.

Every recursive function must have a base condition to stop the recursion.

Components of Recursion

  • Base Case – Condition to stop recursion
  • Recursive Case – Function calling itself

How Recursion Works

Recursive calls are stored in the call stack. When the base case is reached, functions return one by one.

Example: Factorial calculation using recursion.

Advantages & Disadvantages

  • ✔ Simplifies complex problems
  • ✔ Cleaner and readable code
  • ✖ Higher memory usage
  • ✖ Risk of stack overflow

Applications of Recursion

  • Factorial and Fibonacci series
  • Tree and graph traversals
  • Divide and conquer algorithms
  • Backtracking problems
  • Sorting algorithms (Quick Sort, Merge Sort)
