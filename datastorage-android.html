Data Storage in Android

Managing Local & Persistent Data in Android Apps

What is Data Storage?

Data Storage in Android allows applications to store user data locally or remotely for later retrieval and usage.

Types of Data Storage in Android

  • SharedPreferences – Store small key-value pairs
  • Internal Storage – Store private app files
  • External Storage – Store public files
  • SQLite Database – Structured local database
  • Room Database – Modern SQLite abstraction

Example: SharedPreferences (Kotlin)

val sharedPref = getSharedPreferences("MyPrefs", MODE_PRIVATE)
val editor = sharedPref.edit()
editor.putString("username", "Jai")
editor.apply()

Room Database

Room is part of Android Jetpack and provides an abstraction layer over SQLite for easier database management.
