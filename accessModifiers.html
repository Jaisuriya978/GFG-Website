Access Modifiers

Control the visibility and accessibility of classes, methods, and variables

What are Access Modifiers?

Access Modifiers are keywords in object-oriented programming used to define the scope and visibility of variables, methods, and classes.

Types of Access Modifiers

  • Public – Accessible from anywhere
  • Private – Accessible only within the same class
  • Protected – Accessible within the same package or subclasses
  • Default – Accessible within the same package

Access Modifier Comparison

Modifier Same Class Same Package Subclass Outside Package
Public ✔ ✔ ✔ ✔
Protected ✔ ✔ ✔ ✖
Default ✔ ✔ ✖ ✖
Private ✔ ✖ ✖ ✖

Why Use Access Modifiers?

  • Improves data security
  • Supports encapsulation
  • Controls access levels
  • Makes code easier to maintain
