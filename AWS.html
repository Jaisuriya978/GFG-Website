AWS Fundamentals

What is AWS?

AWS is a cloud platform by Amazon that provides scalable computing power, storage, databases, networking, and more on a pay-as-you-go basis.

Core AWS Services

  • EC2 – Virtual servers in the cloud
  • S3 – Object storage service
  • RDS – Managed relational databases
  • Lambda – Serverless computing
  • IAM – Identity & Access Management

Compute

EC2, Lambda, ECS, EKS

Storage
