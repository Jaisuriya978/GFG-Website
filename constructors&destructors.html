Constructors & Destructors

Object initialization and memory cleanup in OOPS

What is a Constructor?

A Constructor is a special method that is automatically called when an object is created. It is used to initialize the object.

  • Same name as the class
  • No return type
  • Called automatically

Types of Constructors

  • Default Constructor
  • Parameterized Constructor
  • Copy Constructor (C++)

What is a Destructor?

A Destructor is a special method that is executed when an object is destroyed. It releases resources like memory and files.

  • Called automatically
  • No parameters
  • Used for cleanup

Constructor vs Destructor

Feature Constructor Destructor
Purpose Initialize object Destroy object
Execution At object creation At object destruction
Parameters Allowed Not allowed
Overloading Yes No
