Greedy Algorithm

Making optimal choices at each step

What is a Greedy Algorithm?

A Greedy Algorithm makes the best possible choice at each step with the hope of finding the overall optimal solution.

It does not reconsider previous decisions.

Characteristics

  • Makes locally optimal choice
  • Simple and fast
  • Does not guarantee global optimal solution

When Greedy Works

  • Greedy-choice property
  • Optimal substructure

Common Greedy Problems

  • Activity Selection Problem
  • Fractional Knapsack
  • Huffman Coding
  • Dijkstra’s Algorithm
  • Prim’s Algorithm

Advantages & Disadvantages

  • Easy to implement
  • Efficient performance
  • Not suitable for all problems
  • May produce suboptimal results
