Stack Data Structure

Learn stack operations, LIFO principle, types, and real-world applications

What is a Stack?

A Stack is a linear data structure that follows the LIFO (Last In, First Out) principle. The element inserted last is removed first.

Example: A stack of plates where the top plate is removed first.

Basic Operations

  • Push – Insert an element into the stack
  • Pop – Remove the top element from the stack
  • Peek / Top – View the top element
  • IsEmpty – Check if the stack is empty
  • IsFull – Check if the stack is full

Types of Stack

  • Array Stack
  • Linked List Stack
  • Dynamic Stack

Applications of Stack

  • Function calls and recursion
  • Undo / Redo operations
  • Expression evaluation
  • Syntax parsing
  • Backtracking algorithms
