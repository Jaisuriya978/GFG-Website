Selenium Locators

Techniques to Identify Web Elements in Selenium

What are Locators?

Locators are used in Selenium to identify and locate web elements on a webpage. Selenium WebDriver interacts with these elements to perform actions like click, sendKeys, and submit.

Types of Selenium Locators

  • ID
  • Name
  • Class Name
  • Tag Name
  • Link Text
  • Partial Link Text
  • CSS Selector
  • XPath

ID Locator

Finds elements using the unique ID attribute.

driver.findElement(By.id("username"));

Name Locator

Locates elements using the name attribute.

driver.findElement(By.name("email"));

Class Name Locator

Finds elements using the class attribute.

driver.findElement(By.className("login-btn"));

CSS Selector

Uses CSS patterns to locate elements.

driver.findElement(By.cssSelector("input[type='text']"));

XPath

XPath is used to locate elements using XML path expressions.

driver.findElement(By.xpath("//input[@id='password']"));

Best Practices

  • Prefer ID locator whenever possible
  • Avoid absolute XPath
  • Use relative XPath
  • Keep locators simple and stable
