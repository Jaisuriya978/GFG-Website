Microinteractions

Small interactions that create big user delight

What are Microinteractions?

Microinteractions are small, contained moments within a product that accomplish a single task and provide feedback to users.

Example: Like button animation, form validation message, toggle switch.

Why Microinteractions Matter

  • Improve user experience
  • Provide instant feedback
  • Guide users subtly
  • Make interfaces feel alive

Components of Microinteractions

  • Trigger – User action or system event
  • Rules – What happens after trigger
  • Feedback – Visual/audio response
  • Loops & Modes – Repetition or states

Common Examples

  • Button hover effects
  • Loading spinners
  • Password strength indicator
  • Swipe-to-refresh
  • Notification sounds

Best Practices

  • Keep them subtle
  • Don’t distract users
  • Be consistent
  • Support usability, not decoration

Microinteractions vs Animations

Animations enhance visuals, while microinteractions serve a functional purpose with feedback.
