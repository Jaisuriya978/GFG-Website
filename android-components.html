Android Core Components

Understand the building blocks of Android applications

Activity

An Activity represents a single screen with a user interface.

  • Entry point for user interaction
  • Manages lifecycle (onCreate, onStart, onResume, etc.)
  • Handles UI rendering

Service

A Service runs in the background without a UI.

  • Music playback
  • Downloading files
  • Background data sync

Broadcast Receiver

A Broadcast Receiver responds to system-wide broadcast messages.

  • Battery low notification
  • Incoming SMS
  • Network connectivity changes

Content Provider

A Content Provider manages shared app data.

  • Access contacts
  • Share media files
  • Database interaction

Intents

Intents are used to communicate between components.

  • Explicit Intent
  • Implicit Intent
  • Start Activity or Service
