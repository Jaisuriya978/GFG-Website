Apache Hadoop

Distributed Storage & Processing for Big Data

What is Hadoop?

Apache Hadoop is an open-source framework used to store and process massive amounts of data across clusters of commodity hardware. It enables distributed computing with fault tolerance.

Why Hadoop?

  • Handles huge data volumes
  • Highly scalable
  • Fault-tolerant
  • Cost-effective

Hadoop Architecture

  • HDFS – Distributed file storage
  • YARN – Resource management
  • MapReduce – Data processing
  • Hadoop Common – Utilities and libraries

HDFS (Hadoop Distributed File System)

HDFS stores large files across multiple machines with high reliability.

  • NameNode – Manages metadata
  • DataNode – Stores actual data
  • Secondary NameNode – Checkpointing

MapReduce

MapReduce is a programming model for processing large datasets using parallel computation. 


// Pseudo Flow
Map(key, value) → Intermediate(key, value)
Reduce(key, values) → Final Output

YARN (Yet Another Resource Negotiator)

YARN manages resources and schedules jobs in Hadoop clusters.

  • Resource Manager
  • Node Manager
  • Application Master

Hadoop Ecosystem Tools

  • Hive – SQL-like queries
  • Pig – Data flow language
  • HBase – NoSQL database
  • Sqoop – Data transfer
  • Flume – Log ingestion

Real-World Use Cases

  • Search engines
  • Log analysis
  • Recommendation systems
  • Fraud detection

Advantages of Hadoop

  • Scalable & reliable
  • Handles structured & unstructured data
  • Cost-effective storage
