Interface

Achieve full abstraction and multiple inheritance in OOPS

What is an Interface?

An Interface is a blueprint of a class that contains abstract methods (and constants). It is used to achieve 100% abstraction and supports multiple inheritance.

Key Characteristics

  • All methods are abstract by default
  • Variables are public, static, and final
  • Supports multiple inheritance
  • Implemented using the implements keyword

Interface vs Abstract Class

Feature Interface Abstract Class
Methods Abstract only Abstract + Concrete
Inheritance Multiple Single
Variables public static final Any type
Constructor No Yes

When to Use an Interface?

  • To achieve full abstraction
  • When multiple inheritance is required
  • To define a contract for classes
  • When unrelated classes share common behavior
