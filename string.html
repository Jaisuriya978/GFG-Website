String

A sequence of characters used to represent text and manipulate data.

DSA Basics

What is a String?

A String is a data type used to store a sequence of characters. It is commonly implemented as an array of characters.

Example:

"Hello World"

Common String Operations

  • Length of string
  • Concatenation
  • Comparison
  • Substring
  • Reverse string
  • Character replacement

Built-in Functions

  • length()
  • charAt()
  • substring()
  • toUpperCase()
  • toLowerCase()

String Traversal

Characters can be accessed using index values.

str[i]

Advantages

  • Easy text manipulation
  • Built-in library support
  • Flexible and readable

Disadvantages

  • Immutable in some languages
  • Slower for heavy modifications

Applications of String

  • Text processing
  • Pattern matching
  • Data validation
  • Web development
