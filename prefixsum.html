Prefix Sum

Fast range query optimization technique

What is Prefix Sum?

Prefix Sum is a technique where we precompute cumulative sums of an array to answer range sum queries efficiently.

It reduces time complexity from O(n) to O(1) per query.

How Prefix Sum Works

  • prefix[0] = arr[0]
  • prefix[i] = prefix[i-1] + arr[i]
  • Range Sum = prefix[r] - prefix[l-1]

Types of Prefix Sum

  • 1D Prefix Sum
  • 2D Prefix Sum (Matrix)

Common Problems

  • Range sum queries
  • Subarray sum problems
  • Equilibrium index
  • Rainwater trapping

Advantages & Limitations

  • Very fast queries
  • Simple implementation
  • Extra space required
  • Preprocessing needed
