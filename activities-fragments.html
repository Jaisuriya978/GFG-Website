Activities & Fragments

Core UI Components in Android Development

What is an Activity?

An Activity represents a single screen with a user interface. Every Android app must have at least one activity.

  • Acts as an entry point for user interaction
  • Manages UI components
  • Follows a lifecycle (onCreate, onStart, onResume, etc.)

Simple Activity Example (Kotlin)

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
    }
}

What is a Fragment?

A Fragment is a reusable portion of UI inside an activity. It helps create flexible and modular user interfaces.

  • Can be reused in multiple activities
  • Has its own lifecycle
  • Used in tablets & multi-screen layouts

Simple Fragment Example (Kotlin)

class ExampleFragment : Fragment(R.layout.fragment_example) {
    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        super.onViewCreated(view, savedInstanceState)
    }
}

Activity vs Fragment

  • Activity: Full screen UI component
  • Fragment: Part of an activity
  • Activity: Independent lifecycle
  • Fragment: Depends on Activity lifecycle
