Express.js

Fast, unopinionated, minimalist web framework for Node.js

What is Express.js?

Express.js is a lightweight backend web application framework built on top of Node.js.

It simplifies building REST APIs and web applications.

Key Features

  • Minimal and flexible framework
  • Robust routing system
  • Middleware support
  • Fast server-side development

Middleware in Express

Middleware functions have access to request and response objects and execute code before sending responses.

  • Application-level middleware
  • Router-level middleware
  • Error-handling middleware

Routing

Express provides a powerful routing mechanism to handle HTTP requests.

Use Cases

  • RESTful APIs
  • Backend for web & mobile apps
  • Microservices
