Data Members in OOPS

Variables that represent the state of an object

What are Data Members?

Data members are variables declared inside a class. They store information (state) related to an object and define its properties.

Example of Data Members


class Student {
    int rollNo;
    String name;
    double marks;
}

Types of Data Members

  • Instance Variables
  • Static Variables

Instance Data Members

Instance variables are unique for each object. They are created when an object is instantiated. 


class Car {
    String model;
    int year;
}

Static Data Members

Static data members are shared among all objects. Only one copy exists. 


class Car {
    static String company = "Toyota";
}

Access Control

Data members can be accessed using access modifiers:

  • private
  • default
  • protected
  • public

Advantages of Data Members

  • Store object state
  • Enable encapsulation
  • Improve data security
