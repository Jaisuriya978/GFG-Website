Matrix & Grid

Learn matrix representation, traversal techniques, and grid-based problems

What is a Matrix?

A Matrix is a two-dimensional data structure arranged in rows and columns.

Matrices are widely used to represent grids, tables, images, and graph connections.

Grid Representation

  • 2D arrays are commonly used to represent grids
  • Each cell can be accessed using grid[row][column]
  • Indices usually start from 0

Matrix Traversal Techniques

  • Row-wise traversal
  • Column-wise traversal
  • Spiral traversal
  • Diagonal traversal

Common Matrix & Grid Problems

  • Rotate matrix
  • Search in a sorted matrix
  • Flood fill algorithm
  • Number of islands
  • Shortest path in a grid

Applications of Matrix & Grid

  • Image processing
  • Game boards (Chess, Sudoku)
  • Dynamic programming on grids
  • Graph problems using grids
