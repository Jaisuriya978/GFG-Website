Software Testing Life Cycle

What is STLC?

STLC (Software Testing Life Cycle) is a sequence of activities performed during the testing process to ensure software quality and reliability.

Why STLC is Important

  • Ensures systematic testing
  • Early defect detection
  • Improves product quality
  • Reduces development risk

Phases of STLC

  • Requirement Analysis
  • Test Planning
  • Test Case Design
  • Test Environment Setup
  • Test Execution
  • Test Closure

Requirement Analysis

Testers analyze requirements to identify testable scenarios and potential risks.

Test Planning

Define testing strategy, scope, resources, tools, and schedule.

Test Case Design

Create detailed test cases and prepare test data based on requirements.

Test Environment Setup

Configure hardware and software required to execute test cases.

Test Execution

Execute test cases, log defects, and perform retesting and regression testing.

Test Closure

Evaluate test completion criteria, analyze test results, and prepare test summary reports.

Entry & Exit Criteria

  • Entry: Approved requirements, test plan ready
  • Exit: All critical defects fixed, test cases executed
