UI Layouts in Android

Designing User Interfaces with XML Layouts

What are Android Layouts?

Android layouts define the structure of a user interface in an app. They are written in XML files and stored inside the res/layout folder.

1. LinearLayout

Arranges UI elements in a single direction — either vertically or horizontally. 

<LinearLayout
    android:orientation="vertical"
    android:layout_width="match_parent"
    android:layout_height="match_parent">

    <TextView
        android:text="Hello World"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content" />

</LinearLayout>

2. RelativeLayout

Positions UI elements relative to each other or to the parent container.

  • Align below another view
  • Align to parent top/bottom
  • Center in parent

3. ConstraintLayout

A flexible and powerful layout that allows positioning elements using constraints. Recommended for complex UI designs.

  • Reduces nested layouts
  • Improves performance
  • Supports responsive design

4. FrameLayout

Used to display a single view or stack multiple views on top of each other. Commonly used with Fragments.

5. TableLayout

Arranges UI elements in rows and columns like a table.

Best Practices

  • Use ConstraintLayout for complex UI
  • Avoid deeply nested layouts
  • Use match_parent and wrap_content properly
  • Keep layouts clean and readable
