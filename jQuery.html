jQuery

Write less, do more – Simplifying JavaScript

What is jQuery?

jQuery is a fast, lightweight JavaScript library that simplifies HTML DOM manipulation, event handling, animations, and AJAX.

Why Use jQuery?

  • Simple and concise syntax
  • Cross-browser compatibility
  • Easy DOM manipulation
  • Built-in animations and effects
  • AJAX support

jQuery Syntax

Basic syntax:

$(selector).action();

Example:

$("p").hide();

Common jQuery Selectors

  • $("p") – Select all paragraphs
  • $("#id") – Select by ID
  • $(".class") – Select by class
  • $("*") – Select all elements

Common jQuery Events

  • click()
  • dblclick()
  • mouseenter()
  • mouseleave()
  • keyup()

jQuery Effects

  • hide() / show()
  • fadeIn() / fadeOut()
  • slideUp() / slideDown()
  • animate()

jQuery vs JavaScript

  • jQuery reduces code length
  • JavaScript offers better performance
  • Modern frameworks reduce jQuery usage
