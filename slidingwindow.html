Sliding Window Technique

Efficient approach to solve subarray and substring problems

What is Sliding Window?

The Sliding Window technique is used to process a range of elements in a list or array by maintaining a window of elements.

It helps reduce time complexity from O(n²) to O(n).

Types of Sliding Window

  • Fixed Size Window
  • Variable Size Window

Fixed Size Window

The window size remains constant while sliding through the array.

Example: Maximum sum subarray of size K

Variable Size Window

The window size changes based on conditions.

Example: Longest substring without repeating characters

Applications of Sliding Window

  • Maximum / minimum subarray problems
  • Substring and pattern matching
  • Optimization problems
  • Deque-based window problems

Advantages

  • Improves performance significantly
  • Easy to implement once understood
  • Used in many competitive programming problems
