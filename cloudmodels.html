Cloud Models

Deployment & Service Models in Cloud Computing

Cloud Deployment Models

  • Public Cloud: Owned by third-party providers and shared among multiple organizations.
  • Private Cloud: Dedicated to a single organization, providing more control and security.
  • Hybrid Cloud: Combines public and private clouds for flexibility.
  • Community Cloud: Shared infrastructure among organizations with similar requirements.

Cloud Service Models

  • IaaS (Infrastructure as a Service): Virtualized computing resources such as servers and storage.
  • PaaS (Platform as a Service): Provides platforms for developing, testing, and managing applications.
  • SaaS (Software as a Service): Delivers software applications over the internet on a subscription basis.
  • FaaS (Function as a Service): Enables running individual functions or pieces of code in the cloud without managing servers.

Advantages of Cloud Models

  • Cost-effective and scalable
  • Improved flexibility and resource utilization
  • Enhanced security with private and hybrid clouds
  • Faster deployment of applications
  • Global accessibility
