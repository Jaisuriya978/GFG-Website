Method Overloading

Compile-time polymorphism in Object-Oriented Programming

What is Method Overloading?

Method Overloading allows multiple methods in the same class to have the same name but different parameters. It is also known as compile-time polymorphism.

Rules of Method Overloading

  • Methods must have the same name
  • Parameters must differ in number or type
  • Return type alone cannot distinguish methods
  • Occurs within the same class

Example


class MathUtils {
    int add(int a, int b) {
        return a + b;
    }

    double add(double a, double b) {
        return a + b;
    }
}

Advantages

  • Improves code readability
  • Enhances flexibility
  • Supports polymorphism
  • Makes APIs easier to use
