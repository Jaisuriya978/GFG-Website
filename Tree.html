Tree Data Structure

Understand hierarchical data with Tree structures, types, traversals, and applications

What is a Tree?

A Tree is a non-linear data structure used to represent hierarchical relationships. It consists of nodes connected by edges, with one node designated as the root.

Each tree node can have zero or more child nodes, but only one parent (except the root).

Basic Terminologies

  • Root – Topmost node of the tree
  • Parent – Node having children
  • Child – Descendant of a parent node
  • Leaf – Node with no children
  • Height – Longest path from root to leaf
  • Depth – Distance from root to a node

Types of Trees

  • Binary Tree
  • Binary Search Tree (BST)
  • AVL Tree
  • Red-Black Tree
  • Heap
  • Trie

Tree Traversal Techniques

  • Inorder Traversal (Left → Root → Right)
  • Preorder Traversal (Root → Left → Right)
  • Postorder Traversal (Left → Right → Root)
  • Level Order Traversal (Breadth First)

Applications of Trees

  • File systems
  • Database indexing
  • Expression parsing
  • Routing algorithms
  • Auto-complete features
