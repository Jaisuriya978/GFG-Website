Caching in System Design

Improving performance and reducing database load

What is Caching?

Caching is the process of storing frequently accessed data in a temporary storage layer to improve response time and reduce load on backend systems.

Why Use Caching?

  • Reduces database queries
  • Improves application speed
  • Reduces server load
  • Enhances scalability

Types of Caching

  • Client-Side Cache (Browser caching)
  • CDN Cache
  • Application Cache
  • Database Cache

Caching Strategies

  • Cache Aside (Lazy Loading)
  • Write Through
  • Write Back
  • Read Through

Cache Eviction Policies

  • LRU (Least Recently Used)
  • LFU (Least Frequently Used)
  • FIFO (First In First Out)
  • TTL (Time To Live)

Popular Caching Tools

  • Redis
  • Memcached
  • Cloudflare CDN
  • AWS ElastiCache
