Figma

Design, prototype, and collaborate in one place

What is Figma?

Figma is a cloud-based UI/UX design tool used to create wireframes, prototypes, and high-fidelity designs with real-time collaboration.

Why Use Figma?

  • Real-time collaboration
  • Works directly in the browser
  • Single source of truth
  • Easy developer handoff

Key Features of Figma

  • Frames & Auto Layout
  • Components & Variants
  • Prototyping & interactions
  • Design systems
  • Version history

Figma in UI/UX Workflow

  • User Research → Wireframes
  • UI Design → Components
  • Prototyping → Interactions
  • Developer Handoff → Inspect panel

Figma vs Other Tools

  • Figma – Cloud-based, collaborative
  • Adobe XD – Adobe ecosystem
  • Sketch – macOS only

Best Practices in Figma

  • Use Auto Layout consistently
  • Create reusable components
  • Name layers properly
  • Maintain a design system
