Android Activity Lifecycle

Understand how Android manages activity states

What is Activity Lifecycle?

The Activity Lifecycle defines how an Android activity behaves during different states such as creation, pause, resume, and destruction.

onCreate()

  • Called when the activity is first created
  • Initialize UI components
  • Set up listeners and data binding

onStart()

  • Activity becomes visible to the user
  • Prepare UI for interaction

onResume()

  • Activity enters foreground
  • User can interact with the activity

onPause()

  • Activity partially hidden
  • Save data or pause animations

onStop()

  • Activity no longer visible
  • Release heavy resources

onDestroy()

  • Called before activity is destroyed
  • Clean up resources

Lifecycle Flow Order

onCreate → onStart → onResume → (Running) → onPause → onStop → onDestroy
