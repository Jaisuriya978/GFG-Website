Abstraction

Hiding implementation details and showing only essential features

What is Abstraction?

Abstraction is an OOPS concept that focuses on exposing only relevant details to the user while hiding the internal implementation.

Example: When you drive a car, you use the steering and pedals without knowing how the engine works internally.

How is Abstraction Achieved?

  • Using abstract classes
  • Using interfaces

Benefits of Abstraction

  • Reduces complexity
  • Improves code readability
  • Enhances security
  • Supports scalability

Real-World Example

Consider a payment system where users can pay via UPI, card, or net banking. The user only interacts with a common payment interface, not the internal logic.
