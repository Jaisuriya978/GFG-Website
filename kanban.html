Kanban

Visual Workflow Management System

What is Kanban?

Kanban is an Agile methodology that focuses on visualizing work, limiting work in progress, and maximizing flow. It helps teams deliver continuously without fixed iterations.

Kanban Principles

  • Visualize the workflow
  • Limit Work In Progress (WIP)
  • Manage flow
  • Make process policies explicit
  • Implement feedback loops
  • Improve collaboratively

Kanban Board

  • To Do
  • In Progress
  • Testing
  • Done

Each task moves across columns until completion.

Key Metrics

  • Lead Time
  • Cycle Time
  • Throughput

Advantages of Kanban

  • Continuous delivery
  • Flexible workflow
  • Improves visibility
  • Reduces bottlenecks

Kanban vs Scrum

  • Kanban has no fixed sprint
  • Scrum works in time-boxed sprints
  • Kanban focuses on flow
  • Scrum focuses on iterations
