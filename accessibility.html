Designing for everyone, without barriers

What is Accessibility?

Web Accessibility ensures that websites and applications are usable by people with disabilities including visual, auditory, motor, and cognitive impairments.

Why Accessibility Matters

  • Inclusive user experience
  • Legal and compliance requirements
  • Better usability for all users
  • Improves SEO and performance

WCAG Principles (POUR)

  • Perceivable – Content can be seen or heard
  • Operable – Usable via keyboard and assistive tech
  • Understandable – Clear and predictable UI
  • Robust – Compatible with assistive technologies

Common Accessibility Practices

  • Use semantic HTML
  • Provide alt text for images
  • Ensure sufficient color contrast
  • Support keyboard navigation
  • Use ARIA labels when needed

Accessible HTML Example

<button aria-label="Close menu">
    ✖
</button>
