Bootstrap 5

A powerful CSS framework for building responsive and modern websites.

CSS Framework

What is Bootstrap 5?

Bootstrap 5 is the latest version of the popular open-source framework developed by Twitter. It offers a wide range of HTML, CSS, and JavaScript tools to create responsive and mobile-first websites.

<link href="bootstrap.min.css" rel="stylesheet">

Key Features

  • Mobile-first grid system
  • No jQuery dependency
  • Utility-first classes
  • Improved forms & components
  • Dark mode support

Popular Components

  • Navbar
  • Buttons
  • Cards
  • Modals
  • Carousel

Utility Classes

  • Spacing (m-, p-)
  • Flexbox utilities
  • Text & color helpers
  • Display utilities

Bootstrap Grid System

Bootstrap uses a 12-column grid layout to create responsive designs.

<div class="row">
  <div class="col-md-6">...</div>
  <div class="col-md-6">...</div>
</div>
