Selenium

Automation Testing Framework

What is Selenium?

Selenium is an open-source automation testing tool used to automate web applications across different browsers and platforms. It supports multiple programming languages like Java, Python, C#, and JavaScript.

Why Use Selenium?

  • Open-source and free
  • Supports multiple browsers (Chrome, Firefox, Edge)
  • Supports multiple programming languages
  • Cross-platform compatibility
  • Strong community support

Components of Selenium

  • Selenium IDE – Record and playback tool
  • Selenium WebDriver – Automates browsers directly
  • Selenium Grid – Runs tests in parallel

Selenium WebDriver

Selenium WebDriver interacts directly with the browser and does not require a separate server. It is the most widely used Selenium component.

Supported Browsers

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
  • Opera

Supported Languages

  • Java
  • Python
  • C#
  • JavaScript
  • Ruby

Advantages of Selenium

  • Reduces manual effort
  • Reusable test scripts
  • Faster test execution
  • Integration with TestNG, JUnit, Maven

Limitations of Selenium

  • Cannot automate desktop applications
  • No built-in reporting
  • Requires programming knowledge
