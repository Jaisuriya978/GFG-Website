Hashing

Efficient data storage and fast retrieval

What is Hashing?

Hashing is a technique used to map data to a fixed-size value using a hash function for fast access.

It allows insertion, deletion, and search operations in average O(1) time.

Hash Function

A hash function converts a key into an index in a hash table.

  • Should be fast to compute
  • Should distribute keys uniformly
  • Should minimize collisions

Collision Handling Techniques

  • Chaining
  • Open Addressing
  • Linear Probing
  • Quadratic Probing
  • Double Hashing

Hash Table

A Hash Table stores key-value pairs and uses hashing to quickly locate data.

  • Fast lookup
  • Dynamic size
  • Widely used in databases and caches

Applications of Hashing

  • Data indexing
  • Password storage
  • Duplicate detection
  • Symbol tables
  • Caching mechanisms

Advantages & Limitations

  • Very fast operations
  • Efficient memory usage
  • Performance depends on hash function
  • Collisions cannot be fully avoided
