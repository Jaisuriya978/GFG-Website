Intents in Android

Communication Between Android Components

What is an Intent?

An Intent is a messaging object used to request an action from another app component (Activity, Service, Broadcast Receiver).

Types of Intents

  • Explicit Intent – Used to start a specific Activity.
  • Implicit Intent – Used to perform actions like opening browser, sending email, etc.

Explicit Intent Example (Kotlin)

val intent = Intent(this, SecondActivity::class.java)
startActivity(intent)

Passing Data Using Intent

val intent = Intent(this, SecondActivity::class.java)
intent.putExtra("username", "Jai")
startActivity(intent)

Receiving Data in Second Activity

val name = intent.getStringExtra("username")

Implicit Intent Example

val intent = Intent(Intent.ACTION_VIEW)
intent.data = Uri.parse("https://www.google.com")
startActivity(intent)

Advantages of Intents

  • Component communication
  • Data transfer between Activities
  • Trigger system-level actions
  • Supports inter-app communication
