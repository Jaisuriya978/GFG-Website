Cloud Computing

Delivering computing services over the internet on demand.

Cloud Fundamentals

What is Cloud Computing?

Cloud Computing provides on-demand access to computing resources such as servers, storage, databases, networking, and software over the internet.

IaaS

Infrastructure as a Service – virtual machines, storage, networks.

PaaS

Platform as a Service – build and deploy applications.

SaaS

Software as a Service – ready-to-use cloud applications.

Deployment Models

  • Public Cloud
  • Private Cloud
  • Hybrid Cloud
  • Multi-Cloud
