Members in OOPS

Data Members, Member Functions & Class Members

What are Members in OOPS?

In Object-Oriented Programming, members are the components of a class that define its behavior and state. Members are accessed through objects and play a vital role in encapsulation.

Types of Members

  • Data Members (Variables)
  • Member Functions (Methods)
  • Constructors
  • Static Members

Data Members

Data members store the state of an object. Each object has its own copy of non-static data members. 


class Student {
    int id;
    String name;
}

Member Functions

Member functions define the behavior of a class. They operate on data members. 


class Student {
    void display() {
        System.out.println("Student Details");
    }
}

Static Members

Static members belong to the class rather than objects. They are shared across all instances. 


class College {
    static String collegeName = "ABC College";
}

Access Control of Members

  • private
  • default
  • protected
  • public

Advantages of Using Members

  • Encapsulation of data
  • Improved code readability
  • Code reusability
  • Better maintenance
