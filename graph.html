Graph Data Structure

Learn graph types, operations, representations, and real-world applications

What is a Graph?

A Graph is a non-linear data structure consisting of vertices (nodes) and edges connecting pairs of vertices. Graphs are used to represent relationships between entities.

Example: Social networks where users are vertices and friendships are edges.

Graph Representations

  • Adjacency Matrix – 2D matrix to represent connections
  • Adjacency List – List of neighbors for each vertex

Types of Graph

  • Directed Graph (Edges have direction)
  • Undirected Graph (Edges have no direction)
  • Weighted Graph (Edges have weights)
  • Unweighted Graph (Edges have no weights)
  • Connected and Disconnected Graphs
  • Cyclic and Acyclic Graphs

Basic Operations

  • Add Vertex – Add a new vertex to the graph
  • Add Edge – Add an edge between two vertices
  • Remove Vertex – Delete a vertex and its associated edges
  • Remove Edge – Delete a specific edge
  • Traversal – Visit all vertices (BFS, DFS)

Applications of Graph

  • Social networks analysis
  • Network routing algorithms
  • Dependency resolution (e.g., build systems)
  • Shortest path algorithms (Dijkstra, Bellman-Ford)
  • Recommendation systems
