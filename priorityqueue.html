Priority Queue

Queue where elements are processed based on priority

What is a Priority Queue?

A Priority Queue is a special type of queue where each element is associated with a priority, and elements are dequeued based on their priority rather than insertion order.

Types of Priority Queue

  • Min Priority Queue – Element with lowest priority is served first
  • Max Priority Queue – Element with highest priority is served first

Implementation Methods

  • Using Arrays
  • Using Linked Lists
  • Using Heap (Most efficient)

Basic Operations

  • Insert element
  • Delete highest/lowest priority element
  • Peek
  • Check if empty

Time Complexity

  • Insertion – O(log n)
  • Deletion – O(log n)
  • Peek – O(1)

Applications of Priority Queue

  • CPU scheduling
  • Dijkstra’s shortest path algorithm
  • Prim’s Minimum Spanning Tree
  • Job scheduling systems

Advantages & Disadvantages

  • Efficient access to highest priority element
  • Flexible and powerful
  • Complex implementation
  • Higher memory usage
