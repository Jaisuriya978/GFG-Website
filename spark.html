Apache Spark

Fast, Unified Analytics Engine for Big Data

What is Apache Spark?

Apache Spark is an open-source distributed computing system designed for fast processing of large-scale data. It performs in-memory computation, making it much faster than traditional MapReduce.

Why Apache Spark?

  • Up to 100x faster than Hadoop MapReduce
  • Supports batch & real-time processing
  • Easy APIs (Java, Python, Scala, R)
  • Advanced analytics support

Spark Architecture

  • Driver Program – Controls execution
  • Cluster Manager – Resource allocation
  • Executors – Execute tasks
  • Tasks – Smallest unit of work

RDD (Resilient Distributed Dataset)

RDD is Spark’s fundamental data structure. It is immutable, fault-tolerant, and distributed across nodes.

Spark Components

  • Spark Core
  • Spark SQL
  • Spark Streaming
  • MLlib
  • GraphX
