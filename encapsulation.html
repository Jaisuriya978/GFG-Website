Encapsulation

Wrapping data and methods into a single unit.

OOP Pillar

What is Encapsulation?

Encapsulation is the process of binding data (variables) and methods into a single unit (class) and restricting direct access to some of the object's components.

Encapsulation Example (Java)

class Account {
    private double balance;

    public double getBalance() {
        return balance;
    }

    public void setBalance(double amount) {
        if(amount > 0) {
            balance = amount;
        }
    }
}

How Encapsulation Works

  • Data members are declared private
  • Access is provided using public getters and setters
  • Improves security and control

Advantages

  • Data hiding
  • Improved maintainability
  • Controlled access

Real-world Example

ATM machine hides internal logic and exposes only necessary operations like withdraw and balance check.

Encapsulation vs Data Abstraction

Encapsulation Abstraction
Focuses on data hiding Focuses on hiding implementation
Uses access modifiers Uses interfaces/abstract classes
