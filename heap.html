Heap

Complete Binary Tree with Priority-based access

What is a Heap?

A Heap is a special tree-based data structure that satisfies the heap property and is implemented using a complete binary tree.

Types of Heap

  • Max Heap – Parent node is greater than or equal to its children
  • Min Heap – Parent node is smaller than or equal to its children

Basic Operations

  • Insert an element
  • Delete root element
  • Peek (Get min/max)
  • Heapify
  • Build Heap

Heap Properties

  • Complete binary tree
  • Stored using arrays
  • Height is log(n)
  • Insertion and deletion take O(log n)

Applications of Heap

  • Priority Queue implementation
  • Heap Sort
  • Scheduling algorithms
  • Graph algorithms (Dijkstra, Prim)

Advantages & Disadvantages

  • Efficient access to min/max element
  • Good performance for priority-based tasks
  • Searching arbitrary elements is slow
  • Complex implementation compared to arrays
