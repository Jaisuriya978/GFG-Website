Databases in System Design

Choosing the right data storage for scalable systems

What is a Database?

A database is an organized collection of data that allows efficient storage, retrieval, and management of information in applications.

Types of Databases

  • Relational (SQL): MySQL, PostgreSQL, Oracle
  • NoSQL: MongoDB, Cassandra, DynamoDB
  • In-Memory: Redis
  • NewSQL: CockroachDB

SQL Databases

  • Structured schema with tables and relations
  • Supports ACID properties
  • Best for transactional systems

NoSQL Databases

  • Schema-less and flexible
  • Scales horizontally
  • Used for big data and real-time systems

Database Replication

  • Copies data across multiple servers
  • Improves availability
  • Supports read scalability

Database Sharding

  • Splits data across multiple databases
  • Improves write scalability
  • Complex to manage
